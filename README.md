# RightTriangleChecker

Определение прямоугольного треугольника

## Описание проекта

Программа определяет, является ли треугольник прямоугольным по длинам трёх его сторон.

Данные о сторонах треугольника хранятся в бинарном файле "triangle.bin".

## Как работает программа

1. Записывает три стороны треугольника в бинарный файл.
2. Считывает значения сторон из файла.
3. Проверяет, существует ли треугольник с такими сторонами.
4. Проверяет, является ли треугольник прямоугольным с помощью теоремы Пифагора.
5. Выводит результат проверки.

## Проверка прямоугольного треугольника

Для определения прямого угла используется теорема Пифагора:

a² + b² = c²

где "c" — гипотенуза, а "a" и "b" — остальные стороны.

Программа проверяет все три возможных варианта расположения гипотенузы.

Пример работы

Входные данные: 3, 4, 5.

Результат:
Прямоугольный треугольник со сторонами: 3 4 5

## Обработка ошибок

Программа проверяет:

- Успешность открытия бинарного файла.
- Успешность чтения данных.
- Возможность существования треугольника с указанными сторонами.

## Запуск программы

1. Открыть проект в среде разработки Visual Studio.
2. Собрать и запустить программу.
3. Получить результат проверки в консоли.
